# neural-graphics-playbook-assets

Asset repository for the **Neural Graphics Playbook** educational course.

## Purpose
This repository stores video files referenced throughout the course.

## Structure
- `/videos/` — course video assets (organized by lesson or module)

## Usage
1. Add course video files to `/videos/`.
2. Use descriptive file names (for example: `module-01-introduction.mp4`).
3. Reference the raw file URLs from your course materials as needed.
